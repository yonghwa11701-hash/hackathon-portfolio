# Yong Hwa Hong — Hackathon Portfolio

I build prototypes that connect clinical problems, AI evaluation and practical user needs. This portfolio describes my contributions to team projects; it does not claim sole authorship.

## Horus — Accel AI Hackathon

An AI consultation-assistant prototype that uses consultation transcripts to suggest questions patients can ask and generate plain-language summaries. Producer agents are paired with evaluator agents and a revision loop.

**My contributions**
- Contributed to the AI agent workflow and user interface.
- Developed synthetic consultation scenarios and clinical test cases, including ambiguous medication doses and unsupported medical advice.
- Helped define acceptance criteria and explain the clinical use case in the pitch.

Built with a five-person team. This is a hackathon prototype, not a clinically validated medical product.

[Public repository on my GitHub](https://github.com/yonghwa11701-hash/Horus)
